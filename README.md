## What it is

One front page — a single 1024×1024 PNG — summing up **40 world news stories
from Tuesday 17 November 2026**, across 6 continents. Three lead stories get
full cards with original flat illustrations drawn from Pillow primitives;
nine more get mid-size cards with icon panels; the remaining 28 are
one-liners, and stories 1–12 are pinned on a dot-matrix world map.

Every story here happened or was first reported on Tuesday 17 November 2026.
Contested claims are marked as claims. Sources: Reuters, AP, AFP, BBC,
Al Jazeera, WHO, UN. All drawings are original.

## How to run

```bash
python3 build_image.py   # writes entry.png (1024x1024, deterministic)
python3 main.py          # copies entry.png to $MAKEFUN_OUTPUT_DIR/entry.png
```

Python 3 stdlib + Pillow only. No network access. Running `build_image.py`
twice produces byte-identical output.
